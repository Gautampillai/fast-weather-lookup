<H1> Fast Weather Lookup - Hash Map vs. Tries </h1>
The purpose of this project is to compare Hash Maps and Tries through time and space complexities. To accomplish this, 
we created console program that looks up a US station's weekly weather records from 2016 using a Hash Map or a Trie. 
With either data structure, the time taken to look up these records are shown along with other stats. This program must be run with 
weather_cli.

<h2> How to Run </h2>

1. Click the Code button and click Download ZIP
2. Once downloaded, extract the ZIP file
3. Using CLion, open the folder that was extracted as a project
4. Once the project is open, right-click CMakeLists.txt and click "Load CMake Project"
5. After loading CMake, click the build button on the top-side of the window
6. Once built, go to the extracted file in explorer and go to [fast-weather-lookup-main/cmake-build-debug/weather_cli.exe] to run the program
7. In weather_cli.exe, you can interact with the CLI to search/insert/delete and benchmark each data structure as per your selections

Apologies for this convoluted way of running the program. If there are any issues when trying to run the program, please let us know.
